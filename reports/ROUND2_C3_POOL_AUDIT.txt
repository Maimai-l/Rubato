Root cause and repair
---------------------
`scripts/c3_timbre_copies.py` stage 3 wrote a label for every selected source
row, including rows whose segment had not been produced by stage 2.  It also
preserved repeated `utt_id`s.  The assembler correctly rejected those rows,
so they did not enter the effective training pool, but they obscured the
input accounting.

The generator now:

  * writes a C3 staging label only when `<utt_id>.opus` or `<utt_id>.flac`
    exists in `work/pdmx_audio_s2`;
  * keeps only the first occurrence of each C3 `utt_id`; and
  * provides `--stage-only` to rebuild labels from existing C3 artifacts
    without rendering again.
